# 法令参照の注釈手引き

この手引きは、抽出器の規則を見ずに、文の表面だけから参照を付けるための決まりである。迷ったら `cite` にし、この文書の「迷いやすい例」に追記する。

注釈するときは、対象の文だけでなく `articleText`（同じ条の本文全体）と、その法令の中の「以下「…」という」を含む文を見る。必要なら e-Gov の法令ページ `https://laws.e-gov.go.jp/law/{lawId}` で前後を確かめる。

## 1件の参照

1つの参照は、**法令の言及から条項の終わりまで**である。

| 本文 | start–end に含める範囲 | 含めない |
| --- | --- | --- |
| 民法第九十条 | 民法第九十条 | |
| 同法第三条第一項 | 同法第三条第一項 | |
| 前条 | 前条 | |
| 民法の規定により | 民法 | の規定により |
| 民法（明治二十九年法律第八十九号）第九十条 | 民法（明治二十九年法律第八十九号）第九十条 | 直後の「の規定」など |

法令名だけの言及も1件である。「民法の規定により無効となる」なら参照は「民法」1件。

`mention` は文の `text.slice(start, end)` と必ず一致させる。オフセットは JavaScript の文字列インデックス（UTF-16）。

## 並列と範囲

- 並列は分ける。「民法第一条、第二条及び第三条」は3件。それぞれの `tgtPid` は `m.a1` / `m.a2` / `m.a3`。2件目以降に法令名がなくても、直前の法令を引き継ぐ。
- 「及び」「並びに」「又は」「若しくは」「、」「・」で条が並ぶときは、並んだ条ごとに1件。
- 範囲は1件。「第三条から第五条まで」は1件。始まりを `tgtPid`、終わりを `tgtEnd` に書く（例: `tgtPid=m.a3`、`tgtEnd=m.a5`）。
- 「第三条第一項から第三項まで」も1件。`tgtPid=m.a3.p1`、`tgtEnd=m.a3.p3`。
- 並列と範囲が混ざるとき（「第一条、第二条から第四条まで及び第五条」）は、範囲のかたまりを1件、単独の条を各1件。

## 参照先（tgtLaw / tgtStatus / tgtPid）

| 相手 | tgtLaw | tgtStatus |
| --- | --- | --- |
| 施行中の他法令 | その lawId | `current` |
| 廃止・失効の法令 | その lawId | `repealed` |
| 改正法（e-Gov に単独の法令として無い号） | `null` | `amendingLaw` |
| 自分自身（この法律・前条・同項など） | 自分の lawId | `self` |
| 法令ごとには解けない | `null` | `unknown` |

- 条項は pid で書く。文法はデータ仕様どおり（本則 `m`、附則 `s1`…、別表 `t1`…、条 `.a3_2`、項 `.p1`、号 `.i1`）。
- 条までしか分からなければ条まで（`m.a90`）。項まで分かるなら項まで（`m.a90.p1`）。
- 法令単位の言及（条がない）は `tgtPid=null`。
- 「第○条の二」は `m.a{n}_2`。民法第三百九十八条の二第一項は `m.a398_2.p1`。
- 項番号のない第1項も `p1`。
- 条のない法令は `m.p1` のように項から書く。
- 附則の第一条は `s1.a1`（その文書で何番目の `SupplProvision` か）。

法令名の引き方（注釈者用。抽出器の規則ではない）:

1. 法令番号（「明治二十九年法律第八十九号」）が本文にあれば、コーパスの `num` / `numNorm` で引く。
2. 正式名称があれば `title` で引く。
3. 「以下「金商法」という」で定義された略称は、その定義の範囲内で `abbrevs` および本文定義を使う。
4. 「同法」は、同じ文または直前の文で出た他法令を指す。条の中の直前の他法令が複数あるときは、いちばん近くてまだ有効なものを採る。
5. どうしても引けなければ `tgtLaw=null`、`tgtStatus=unknown`。

## 種類（8種から1つ）

複数当てはまるときは、次の順で先のものを採る。判断に迷ったら `cite` にし、下の「迷いやすい例」に残す。

1. **basis** 制定の根拠。制定文や「○○法第十条の規定に基づき、この政令を制定する」など。
2. **implements** 委任の受け皿。施行令・施行規則側の「法第○条の政令で定める○○は」など、上位法の委任を受けて中身を置く言及。
3. **amend** 改正・廃止。「○○法の一部を次のように改正する」「○○法を廃止する」。
4. **junyo** 準用。「○○について準用する」「準用する」。
5. **rei** 例による。「○○の例による」。
6. **exclude** 適用除外。「○○は、適用しない」「○○の規定は、適用しない」。
7. **term** 定義・用語の借用。「○○法に規定する△△」「○○法第二条に定めるところによる」で、条項の効力ではなく語の意味を借りているとき。
8. **cite** 引用。上のどれにも当てはまらない、規定の指示・適用・読み合わせ。

`yomikae` は種類ではなく印である。読替え（「…とあるのは…と読み替える」）を伴う参照なら `true`。種類は文脈どおり（多くは `junyo` または `cite`）。

## 付けないもの

- カギ括弧の中（定義語、改正後の文言、読替えの文言）にある条項・法令名は参照にしない。
  - 「以下「金商法」という」の「金商法」は参照ではない（定義そのもの）。定義の直前にある正式名称「金融商品取引法（…）」は参照である。
  - 「「第三条」を「第四条」に改める」のカギ括弧内は参照ではない。改正の対象法令が外にあれば、そちらを `amend` にする。
  - 「同法第四条中「前項」とあるのは「第一条」と読み替える」の「前項」「第一条」は参照にしない。外の「同法第四条」は参照（`yomikae=true`）。
- 見出しだけ（条名「第三条」、項番号）は文のテキストに含まれない前提なので注釈しない。
- 単なる一般名詞の「方法」「憲法上の権利」など、個別の法令を指していないものは参照ではない。

## 法令内の相対参照

次は自分の法令への参照（`tgtStatus=self`）として付ける。

- 前条・次条・前項・次項・前号・次号
- 同条・同項・同号（他法令の「同法」に続かないとき）
- 本条・この条・この項・この号（条項を指しているとき）

「この法律」単体で条項を伴わないものは、**付けない**（量が多く、他法令の言及と混ざるため）。「この法律第三条」は1件（`self`、`tgtPid=m.a3`）。

## 具体例

### 例1 他法令・条まで（cite）

文: `民法第九十条の規定により無効とする。`

- `{ start:0, end:6, mention:"民法第九十条", tgtLaw:"129AC0000000089", tgtStatus:"current", tgtPid:"m.a90", tgtEnd:null, kind:"cite", yomikae:false }`

### 例2 法令名だけ

文: `民法の規定により無効とする。`

- `{ mention:"民法", tgtPid:null, kind:"cite" }`

### 例3 並列

文: `民法第一条、第二条及び第三条の規定を準用する。`

- 3件。いずれも `kind:"junyo"`。mention は `民法第一条` / `第二条` / `第三条`。2件目以降の `tgtLaw` は民法。

### 例4 範囲

文: `第三条から第五条までの規定は、適用しない。`

- 1件。`mention:"第三条から第五条まで"`, `tgtStatus:"self"`, `tgtPid:"m.a3"`, `tgtEnd:"m.a5"`, `kind:"exclude"`。

### 例5 同法

文: `金融商品取引法第二条第九項に規定する金融商品取引業者（同法第二十八条第一項に規定する第一種金融商品取引業を行う者に限る。）`

- 1件目: `金融商品取引法第二条第九項`（`term` または迷えば `cite`）
- 2件目: `同法第二十八条第一項`（同じ lawId、`cite`）

### 例6 略称定義

文: `金融商品取引法（昭和二十三年法律第二十五号。以下「金商法」という。）`

- 参照は `金融商品取引法（昭和二十三年法律第二十五号）` 1件だけ。「金商法」は付けない。

### 例7 施行令の受け皿（implements）

文: `法第十二条の政令で定める事項は、次のとおりとする。`

- この文が施行令の本則にあり、「法」が親法律を指すなら 1件。`kind:"implements"`。`tgtPid` は親法律の第十二条。

### 例8 制定の根拠（basis）

文: `地方自治法第二百五十二条の十七の五の規定に基づき、この政令を制定する。`

- 1件、`kind:"basis"`。

### 例9 改正（amend）

文: `民法の一部を次のように改正する。`

- 1件、`kind:"amend"`。`tgtPid=null`。

### 例10 例による（rei）

文: `前条の規定は、前項の場合について準用する。` ではなく、`国税通則法の例による。`

- 1件、`kind:"rei"`。

### 例11 読替え

文: `前条の規定を準用する。この場合において、同条中「許可」とあるのは「届出」と読み替えるものとする。`

- 1件目: `前条`（`junyo`、`yomikae=true`、`self`）
- 「許可」「届出」は参照にしない。

### 例12 参照なし（誤検出用）

文: `この省令は、公布の日から施行する。`

- `refs: []`

## 迷いやすい例（判断に迷って cite にしたもの）

注釈中に迷った文は、ここに gid と理由を追記する。

- 「…に規定する」が定義の借用か、規定の適用か分からないときは `cite`（`term` にしない）。
- 「基づき」でも、制定文でなく個別処分の根拠なら `cite`（`basis` にしない）。
- g196: 省令の題名「…法第十三条第一項の…に関する省令」の中の親法律の条は分けない。題名全体を1件（その省令）。
- g246: 「少年法第六条の二第三項の規定に基づく…規則（平成十九年国家公安委員会規則第二十三号）」も題名＋法令番号で1件。題名の中の親法律の条と「第二十三号」は分けない。

## 記録の形

1文1行。

```json
{
  "gid": "g001",
  "annotator": "c1",
  "refs": [
    {
      "start": 0,
      "end": 6,
      "mention": "民法第九十条",
      "tgtLaw": "129AC0000000089",
      "tgtStatus": "current",
      "tgtPid": "m.a90",
      "tgtEnd": null,
      "kind": "cite",
      "yomikae": false
    }
  ]
}
```

- 1人目は `annotator: "c1"`。2人目は `c2`（1人目の `refs` を見ない）。
- 不一致の裁定は `annotator: "final"` で `adjudicated.jsonl` に書く。根拠は下の「迷いやすい例」に gid 付きで残す。
- 2人目に渡す入力は `gold/second-pass-input.jsonl`（文と条本文だけ。1人目の参照は入れない）。
